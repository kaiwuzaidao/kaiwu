## 截图要求

- 浏览器窗口 **1600×900 或更宽**，避免侧栏折叠导致信息丢失
- 使用**浅色主题**，与文档背景一致
- 截图前确认页面**不含真实凭据、真实姓名、内网主机名和 Token**
- PNG 格式；超过 500 KB 请先压缩，仓库不放大图

## 时效

**当前五张拍摄于 2026-09-14**，反映的是那一刻的真实数据：三个项目
（内置 `system`、`reimburse`、`ai-volunteer`），其中 `ai-volunteer` 刚生成完、
尚未推送。

按"多久会过期"分两类：

- **随数据变的**：`workbench.png` 与 `project-factory.png` 拍的是待处理事项和
  生成任务的**即时状态**。上面那个待推送的项目一旦推送完成，这两张就与实际不符了；
- **随界面变的**：`permissions.png`、`dictionary.png`、`projects.png` 展示的是
  页面结构与规则，只在 UI 改版时才会过期。

平台演进后界面会变，截图会过期。改动主要页面时顺手更新这里，
**过期截图比没有截图更容易让人误判**——读者不会怀疑图，只会以为自己装错了。

重拍时按上表逐张核对内容是否仍然对得上，不要只换图不改描述。
